# Retaining Wall Design Suite V7.1

**Retaining Wall Design Suite for Windows**

A desktop application for retaining wall design and engineering calculations.

## Features

- Retaining wall design and analysis
- Engineering calculation workflow
- Desktop application for Windows

## Installation

1. Download the Windows installer (`.exe`) from the [Latest Release](../../releases/latest).
2. Run the downloaded installer.
3. Follow the installation instructions.
4. Launch Retaining Wall Design Suite from the Desktop shortcut or Start Menu.

## How to Download

Visit the [Releases page](../../releases) and download the latest Windows installer.

## System Requirements

- Microsoft Windows
- A compatible 64-bit Windows computer

## Version

Current release: **V7.1.0**

## Disclaimer

Verify all design inputs, assumptions, calculations, and applicable engineering standards before using results for actual construction. The engineer responsible for the project must independently review and approve the design.
